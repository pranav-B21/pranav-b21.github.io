Papers

Integrating Collaborative and Meta-Information Retrieval with Reasoning: An End-to-End Framework for LLM-Based Recommendation

In Progress

Shijun Li, Joydeep Ghosh, Pranav Belligundu

We propose an end-to-end framework for LLM-based recommendation that unifies collaborative filtering signals with meta-information retrieval and structured reasoning. Rather than treating retrieval and generation as separate stages, our approach enables the model to autonomously query user interaction histories and item metadata via retrieved-token masking, then apply chain-of-thought reasoning to produce grounded, explainable recommendations. Trained with PPO on large-scale datasets, the system learns to balance exploration of novel items with exploitation of known preferences, yielding improvements in both accuracy and recommendation diversity.

Selected Projects

Recurse

An MCP server for Claude Code that analyzes massive codebases without consuming the agent's token budget. Recurse implements a Recursive Language Model (RLM) pattern: it offloads queries to a local Qwen model running through Ollama, which recursively decomposes the question, walks the repository, and reasons over millions of tokens before returning a single distilled answer to Claude. This keeps the primary context window free while still grounding responses in the full codebase, and supports configurable backends, recursion depth, and iteration limits so the depth of analysis can be tuned per query.

Python · MCP (Model Context Protocol) · Ollama · Qwen 3.5 · OpenAI API · Recursive LLM

Apanto

An intelligent AI model router that automatically selects the best model for each prompt based on task type and a chosen priority — accuracy, speed, or cost. Apanto classifies the incoming prompt, scores candidate models, and routes across OpenAI, Anthropic, Google Gemini, DeepSeek, and Groq (Llama), while also letting users self-host their own Hugging Face models alongside the premium APIs. The full-stack app pairs a React + TypeScript frontend (Vite, shadcn/ui, Tailwind) with a FastAPI backend, surfacing real-time analytics on latency, cost, and usage, plus AI-powered prompt enhancement, all backed by a Supabase/PostgreSQL store for model scoring and metadata.

React 18 · TypeScript · Vite · Tailwind CSS · shadcn/ui · React Query · FastAPI · Python · Pydantic · PostgreSQL (Supabase) · Hugging Face Transformers · PyTorch · CUDA · OpenAI / Anthropic / Gemini / DeepSeek / Groq APIs
